# 智股助手 StockPilot —— 需求文档

> 版本：v7.2.0　日期：2026-09-08　状态：已实施并全量自测（错误呈现规范：弹窗报错+状态区短文案，242 单测，见设计文档 §56.5）
>
> 本文档为「Windows 本地股票分析客户端」项目的需求基线。设计见 [设计文档](./设计文档.md)。

---

## 1. 背景与目标

用户希望借助开源社区成熟方案，获得一个**开箱即用**的 Windows 本地客户端工具，用于：

- 看行情（指数、个股实时行情、K 线图）
- 选票（全市场条件选股 + 技术指标筛选 + AI 点评）
- 炒股辅助（自选管理、资讯聚合、AI 诊断与操作建议）
- 自动接入外部信息数据源（免配置、开箱可用）
- 接入外部 AI 分析（**标准 OpenAI 协议**，支持主流模型厂商 + 自定义厂商）

最终交付物为**单个 exe 可执行文件**（无需安装 Python 环境），且源码结构清晰、便于后期维护与二次开发。

## 2. 开源项目调研与选型

### 2.1 候选项目对比（2026-09 通过 GitHub API 核实）

| 项目 | Stars | 语言/技术栈 | 形态 | 与需求匹配度 | 主要差距 |
|---|---|---|---|---|---|
| [TauricResearch/TradingAgents](https://github.com/TauricResearch/TradingAgents) | **102,289** | Python | 多智能体 LLM 交易**框架**（无 GUI） | AI 分析方法论最强（基本面/消息面/情绪面多智能体辩论） | 无图形界面；依赖重（langchain 等），不适合打包为轻量开箱即用 exe |
| [ZhuLinsen/daily_stock_analysis](https://github.com/ZhuLinsen/daily_stock_analysis) | **64,508** | Python | 定时分析+推送系统（企微/飞书/TG） | 多市场分析、多 LLM 支持 | 无 GUI 客户端，面向"推送"而非"桌面交互" |
| [akfamily/akshare](https://github.com/akfamily/akshare) | **22,377** | Python | 财经数据接口库 | 数据源最全 | 是数据**库**而非客户端；依赖 pandas 全家桶，打包体积大 |
| [arvinlovegood/go-stock](https://github.com/arvinlovegood/go-stock) | **7,400** | Go + Wails + Vue | **Windows 桌面 exe**（GPL-3.0） | 形态完全一致：行情/自选/预警/AI 分析/资讯，AI 支持 OpenAI 兼容接口与十余家厂商 | 本机无法构建（见 2.2）；扩展需 Go+前端双栈 |

### 2.2 选型结论

**以 go-stock 为功能蓝本与数据接口参考，以 TradingAgents 的 AI 分析方法论为业务参考，数据端点复用开源生态验证过的免费行情/资讯接口（腾讯/新浪/东方财富，与 go-stock 同源），自研实现本项目 StockPilot。**

选择"基于调研自研"而非直接复用某一仓库的原因：

1. **本机环境无法构建 Go/Wails 项目**：经实测，当前网络环境下 Go 官方中文镜像（golang.google.cn）、Go 模块代理（goproxy.cn/goproxy.io）及各大镜像站全部不可达，Go 工具链与依赖均无法获取，go-stock 无法本地编译和二次开发（源码已通过 GitHub 镜像下载核实其数据接口）。
2. **TradingAgents / daily_stock_analysis 无桌面 GUI**，且依赖链庞大，打包为单文件 exe 后体积与稳定性都不满足"开箱即用"要求。
3. 需求允许"如果项目不支持，请自己完善和实现对应的功能"。自研 Python 栈可在满足全部功能清单的同时保证**单语言技术栈、零重型依赖（仅 PySide6 + requests）**，可维护性最好。

### 2.3 相对参考项目自研补齐的能力

- 标准 **OpenAI Chat Completions 协议**统一接入：厂商预设（OpenAI / DeepSeek / Kimi / 通义千问 / 智谱 GLM / OpenRouter / 硅基流动 / Ollama 本地）+ **自定义厂商**（任意 base_url + api_key + model），支持 SSE 流式输出与连接测试、在线拉取模型列表。
- 免配置数据源：内置腾讯行情（主）、东方财富 K 线/全市场/资讯（主）、新浪行情（备），无需注册 token 即开箱可用。
- 全市场条件选股 + 技术指标引擎（MA/MACD/RSI/KDJ/BOLL 纯 Python 实现，无 pandas 依赖）。
- **用户自定义策略的量化监听**：内置多套盈利导向策略模板，支持规则可视化自定义；程序运行期间自动扫描全市场潜在机会。
- **策略回测**：基于历史日 K 的简易事件驱动回测，输出胜率/盈亏比/最大回撤等指标，帮助用户验证策略有效性后再用于实盘监听。
- **消息推送**：飞书 / 钉钉 / 企业微信群机器人 webhook 接入，出现买卖机会时自动通知。
- 原生 PySide6 桌面 UI（自绘 K 线图），PyInstaller 打包单文件 exe。

## 3. 用户与使用场景

- **目标用户**：A 股个人投资者（也兼容北交所代码识别），在本机使用，注重隐私（自选与配置保存在本地）。
- **典型场景**
  - S1 盘中打开软件，看大盘三大指数与自选股实时涨跌。
  - S2 搜索代码/名称加入自选，双击查看 K 线与技术指标。
  - S3 盘后用选股器按"换手率/涨跌幅/量比/市值/PE/PB + 均线多头/MACD 金叉"筛选，AI 批量点评 Top N。
  - S4 对任一股票发起 AI 诊断（现价、指标、近期新闻注入上下文），流式阅读建议，并多轮追问。
  - S5 浏览 7×24 快讯与个股新闻，一键"让 AI 解读这条新闻对该股的影响"。

## 4. 功能需求

优先级：P0=必须有，P1=应有，P2=可延后。

### FR-1 行情看板（P0）
- FR-1.1 展示上证指数、深证成指、创业板指、科创 50 实时报价与涨跌幅。
- FR-1.2 自选股表格实时刷新（可配置刷新间隔，默认 5 秒，交易时段自动刷新，收盘后降频）。
- FR-1.3 展示：名称、代码、现价、涨跌额、涨跌幅、今开/昨收/最高/最低、成交量、换手率、量比、PE、总市值。
- FR-1.4 搜索框支持代码或名称模糊搜索（拉取全市场列表本地过滤），回车/按钮加入自选。
- FR-1.5 行情源失败自动重试并可在备用源之间切换。

### FR-2 个股详情（P0）
- FR-2.1 K 线图（日/周/月线，最近 120~250 根），含蜡烛图、MA5/10/20/60、成交量副图、十字光标。
- FR-2.2 技术指标面板：MA、MACD（12,26,9）、RSI(6/12/24)、KDJ(9,3,3)、BOLL(20,2) 当前数值与简要状态（金叉/死叉/超买/超卖/多头排列等）。
- FR-2.3 "AI 诊断"按钮：一键把该股实时数据+指标+近期新闻注入 AI 上下文进行分析。

### FR-3 自选管理（P0）
- FR-3.1 添加/删除自选，右键菜单操作；双击打开详情。
- FR-3.2 自选列表本地持久化，重启后恢复。

### FR-4 选股器（P0）
- FR-4.1 拉取沪深京全市场快照（东方财富列表接口，分页自动抓取）。
- FR-4.2 条件筛选（均可勾选并填区间）：现价、涨跌幅、换手率、量比、流通市值、总市值、市盈率、市净率、成交额。
- FR-4.3 技术筛选：对候选结果抽样/全量拉 K 线计算指标，支持"均线多头排列""MACD 金叉""RSI 未超买"等开关。
- FR-4.4 结果排序展示；"AI 点评 Top N"：把前 N 只的基本面与指标摘要交给 AI 逐一点评，输出关注建议与风险提示。

### FR-5 资讯（P1）
- FR-5.1 7×24 市场快讯列表（东方财富），定时刷新。
- FR-5.2 个股新闻/公告：详情页按股票拉取最近新闻标题与链接，可作为 AI 上下文。
- FR-5.3 任一新闻可一键"AI 解读"。

### FR-6 AI 分析（P0，核心）
- FR-6.1 **标准 OpenAI 协议**：POST `{base_url}/chat/completions`，`Authorization: Bearer <key>`，兼容 `/v1/models` 拉取模型列表。
- FR-6.2 内置厂商预设：OpenAI、DeepSeek、Moonshot Kimi、阿里通义千问（DashScope 兼容模式）、智谱 GLM、OpenRouter、硅基流动、Ollama（本地）；以及**自定义厂商**（名称/base_url/api_key/model 全部可填）。
- FR-6.3 多套配置可保存、可切换（例如同时配 DeepSeek 与本地 Ollama）。
- FR-6.4 流式输出（SSE），逐字渲染；同时支持非流式回退。
- FR-6.5 对话模板：个股诊断 / 选股结果解读 / 新闻解读 / 自由问答；支持多轮对话与"清空上下文"。
- FR-6.6 上下文注入：当前股票行情快照、技术指标结论、最近 K 线摘要、新闻标题列表按模板拼装为 system/context 消息。
- FR-6.7 连接测试按钮：校验 base_url/key/model 可用性并给出明确错误提示（网络、鉴权、模型名）。
- FR-6.8 全部回复自动附加"AI 分析仅供参考，不构成投资建议"免责声明。

### FR-7 设置（P0）
- FR-7.1 AI 厂商与模型配置（预设选择、参数编辑、测试、多配置管理）。
- FR-7.2 行情刷新间隔、K 线根数、界面主题（深色/浅色）。
- FR-7.3 HTTP 代理开关（可选，便于访问海外厂商 API）。
- FR-7.4 配置本地持久化（JSON），支持"打开配置目录"。

### FR-8 策略量化监听（P0，核心）
- FR-8.1 **策略模型**：策略 = 名称 + 生效市场范围（全市场/自选）+ 规则组（买入规则、卖出规则）+ 风控参数（止损%、止盈%、最大持有天数、建议仓位上限）。
- FR-8.2 **规则可视化自定义**：每条规则形如"指标 + 运算符 + 阈值"（如 `MACD_DIF > MACD_DEA`、`RSI6 < 30`、`现价 > MA20`、`量比 > 1.5`、`换手率 3%~15%`、`收盘价创 20 日新高`），支持增删改规则并保存多个自定义策略；内置盈利导向策略模板（趋势启动 / 放量突破 / 回调企稳 / 超卖反弹）可直接使用或复制修改。
- FR-8.3 **全市场自动监听**：程序运行期间按配置间隔（默认 5 分钟，交易时段生效）自动拉取全市场快照做粗筛，再对候选股拉日 K 执行策略判定，发现买入/卖出机会即在监听页展示。
- FR-8.4 **机会信号内容**：每条信号包含——时间、代码/名称、命中策略与命中规则明细、现价（**参考买入成本**）、建议止损价、建议目标价、风险评分（0~100，越低越稳）、风险摘要（波动率/偏离均线/消息面提示）、信号理由文本。
- FR-8.5 **卖出监听**：对已产生买入信号（或用户标记"持仓"）的股票持续跟踪卖出规则（止盈/止损/跌破均线/最大持有天数），触发卖出机会通知。
- FR-8.6 **信号去重**：同一股票+同一策略+同一交易日内不重复推送；提供"当日信号"与"历史信号"查看。
- FR-8.7 信号可一键：加入自选 / 查看K线详情 / **AI 交互解读**。

### FR-9 策略回测（P0）
- FR-9.1 回测输入：策略（内置或自定义）、股票范围（自选/手动输入代码列表/全市场按成交额 Top N，默认 Top 50）、区间（最近 N 个交易日，默认 250）、初始资金、佣金费率（默认万 2.5，卖出另计印花税 0.05%）。
- FR-9.2 撮合与风控规则与实盘监听一致：按策略买入规则当日收盘价成交；止损价/止盈价/最大持有天数/跌破均线卖出。
- FR-9.3 输出绩效：总收益率、年化收益、胜率、盈亏比（平均盈利/平均亏损）、最大回撤、交易次数、平均持有天数、期末资金；以及**逐笔交易明细**（代码/买入日价/卖出日价/涨跌幅/持有天数/盈亏额/卖出原因）。
- FR-9.4 结果可一键"AI 解读回测报告"，辅助判断策略是否值得用于实盘监听。
- FR-9.5 回测与监听共用同一策略定义（一处定义，两处生效），避免策略口径不一致。

### FR-10 消息通知（P0）
- FR-10.1 支持**飞书群机器人**、**钉钉群机器人**、**企业微信群机器人**三种 webhook 通道，用户在设置页填入 webhook 地址（钉钉支持加签 secret）即可启用。
- FR-10.2 触发场景：监听发现买入机会 / 卖出机会；可选推送范围（仅买入/买入+卖出）。
- FR-10.3 消息内容：股票、策略、现价（参考成本）、止损/目标价、风险评分、命中规则摘要、免责声明；飞书/企微用文本消息，钉钉自动附加安全关键词"股票机会"以满足机器人关键词校验。
- FR-10.4 通知开关独立于监听开关：可只开监听不推送；发送失败在界面日志提示并自动重试 1 次。
- FR-10.5 设置页提供"发送测试消息"按钮验证连通性。

### FR-11 AI × 策略数据交互（P0）
- FR-11.1 AI 可接收监听信号上下文（命中规则、指标数值、建议买卖价、风险项）做**交互式解读**：判断机会质量、给出分批/仓位参考、列出反向证据。
- FR-11.2 AI 可接收回测报告做解读：指出策略缺陷（过拟合、样本少、单边市依赖等）与改进建议。
- FR-11.3 AI 页支持针对任意信号/回测结果多轮追问；所有 AI 结论标注"仅供参考，不构成投资建议"。

### FR-12 分时图与五档盘口（P0）
- FR-12.1 个股详情提供**分时图** Tab：价格线 + 均价线 + 昨收基准线 + 分时成交量，随行情可刷新。
- FR-12.2 个股详情提供**五档盘口**面板：买一~买五、卖一~卖五价格与量，红绿着色。
- FR-12.3 K 线 Tab 支持 日/周/月 切换（v1.1 已有），与分时 Tab 并列。

### FR-13 持仓管理（P0，炒股核心）
- FR-13.1 独立**持仓页**：手动录入持仓（代码、成本价、数量、日期），实时展示现价、市值、浮动盈亏（额/%）、今日盈亏；页首汇总卡（总市值/总盈亏/今日盈亏）。
- FR-13.2 持仓与**卖出监听联动**：录入持仓后自动纳入策略监听的止损/止盈/卖出规则跟踪。
- FR-13.3 支持修改成本/数量、删除持仓；数据本地保存。

### FR-14 交易记录（P1）
- FR-14.1 手动录入成交流水（日期、代码、方向、价格、数量、费用），支持删除。
- FR-14.2 汇总统计：总买入额、总卖出额、总费用、净投入。
- FR-14.3 流水可导出 CSV。

### FR-15 导出与方案（P1）
- FR-15.1 选股结果、监听信号、交易记录可**一键导出 CSV**（UTF-8 BOM，Excel 直接打开不乱码）。
- FR-15.2 选股条件+技术形态可保存为**方案**并一键加载复用，可删除。

### FR-16 常驻与提醒（P1）
- FR-16.1 **系统托盘**：最小化到托盘常驻（可配置），监听在后台持续运行。
- FR-16.2 发现新信号时：托盘气泡通知（默认开）+ 可选提示音；点击气泡回到主界面。

### FR-17 界面改版（P0，v1.2 已实现）
- FR-17.1 **顶部指数栏**：四大指数实时行情常驻主窗口顶部（任意页面可见），含交易状态（交易中/已收盘）与时间。
- FR-17.2 **专业暗色主题**：统一设计令牌（背景/面板/描边/强调色/涨跌色），卡片化分组、圆角、悬停态；左侧图标导航带选中高亮。
- FR-17.3 **详情窗重构**：报价头条 + 分时/K线 Tab + 右侧五档与指标栏 + 底部消息，符合主流行情软件布局。
- FR-17.4 回测结果以**绩效指标卡 + 收益曲线图**呈现。
- FR-17.5 全部表格统一右对齐数值、涨跌着色、隔行底色、悬停高亮。

### FR-18 选股策略执行闭环（P0，v1.3）
- FR-18.1 **策略库直接选股**：条件选股页新增「按策略选股」模式——选择策略库中任一策略（内置/自定义），对全市场执行其买入规则，产出机会列表；与「条件筛选」模式并列可组合。
- FR-18.2 **机会评分**：每个机会计算 0~100 综合机会分（风险反向、趋势强度、量能、潜在盈亏比、RSI 位置），并给出 A/B/C 评级；列表按机会分排序。
- FR-18.3 **信号有效性跟踪**：每条历史信号记录「发出价 → 现价」的累计涨跌幅，直观验证策略实际效果。
- FR-18.4 内置策略扩充至 7 套（新增：强势回调 / 布林下轨反弹 / 平台突破），覆盖趋势/突破/低吸/反弹/震荡多种打法。

### FR-20 个股 AI 报告就地查看（P0，v1.4）
- FR-20.1 个股详情窗内嵌「AI 报告」Tab：与分时/K线并列；点头部「AI 诊断」直接切到该 Tab 并**自动发起流式分析**，用户在当前窗口阅读，无需跳转主界面。
- FR-20.2 报告 Tab 内可直接**追问**（输入框+发送，多轮上下文延续个股数据），并提供"重新分析"。

### FR-29 中文编码乱码根治（P0，v2.0）
- FR-29.1 **根因**：AI 流式响应用 `iter_lines(decode_unicode=True)` 读取，当服务方 `Content-Type` 不带 `charset=utf-8` 时 requests 按 HTTP 默认 latin-1 解码 UTF-8 字节，中文成 `è¾¾å®` 型乱码。
- FR-29.2 **修复口径**：SSE 一律按**字节读行 + 强制 UTF-8 解码**；AI 错误响应体、通知 webhook 错误体同样强制 UTF-8（`_resp_text_utf8`，GBK 次选）；行情层 `get_text` 在响应头无 charset 或为 latin-1 时用 `apparent_encoding` 探测、兜底 UTF-8。
- FR-29.3 **全链路排查结论**：腾讯/新浪行情与板块接口已有显式 GBK 解码；东财 JSON 走 `resp.json()`（按 RFC 自动 UTF-8）；CSV 导出带 UTF-8 BOM；日志/配置/通知正文均为显式 UTF-8——除上述三处外无其他乱码风险点。
- FR-29.4 验收：无 charset 的 mock SSE 两轮中文对话端到端无乱码；错误体（503）中文原文不乱码；全部既有测试通过。

## 6. 范围与非目标

- **不做**：实盘下单/程序化自动交易（用户明确要求暂不支持，且无公开免鉴权券商接口）；历史分钟级回测（仅日级）；港股/美股完整支持（代码映射已预留，行情接口按 A 股优先实现）。
- 所有分析功能（策略、监听、回测、AI）均以**辅助用户做出盈利性交易决策**为目标，但 AI 输出与策略信号为**研究参考**，不构成投资建议，不承诺收益。

## 7. 验收标准

1. `StockPilot.exe` 在全新 Windows 10/11 x64 机器上双击启动，无需任何安装步骤（NFR-1）。
2. 首次启动即可看到三大指数与默认自选的实时行情（FR-1，NFR-2）。
3. 添加自选 → 查看日 K 与指标 → 数据正确（与主流行情软件偏差在正常范围）。
4. 选股器按"换手率 3~15% + 量比 >1.5 + 流通市值 30~300 亿 + 均线多头"可得到结果列表（FR-4）。
5. 设置中配置任一 OpenAI 兼容厂商（如 DeepSeek）→ 连接测试通过 → 个股诊断流式输出 → 多轮追问正常（FR-6）。
6. 选择"自定义厂商"填入任意 OpenAI 兼容 base_url/key/model 同样可用（FR-6.2）。
7. 断网时操作各页面不崩溃、有错误提示（NFR-4）。
8. `pytest` 单元测试全部通过；`--smoke` 自检通过（NFR-6）。
9. 配置一个自定义策略（如"量比>1.5 且 MACD 金叉"）→ 点击扫描 → 能产出含买入成本/止损/目标/风险评分的信号（FR-8）。
10. 开启自动监听后程序静默运行，盘中自动产生新信号并去重（FR-8.3/8.6）。
11. 对任一策略回测最近 250 日：输出胜率/盈亏比/最大回撤与逐笔明细，数值可复算（FR-9）。
12. 填入飞书/钉钉 webhook → 测试消息送达群聊（FR-10.5）；触发信号时群内自动收到推送（FR-10.2）。

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 腾讯/东财/新浪为非官方公开接口，字段可能变化 | 解析层集中且防御式（缺字段返回 None 不崩溃）；数据源注册化，便于新增/切换；核心字段解析有单测 |
| 海外 AI 厂商直连不通 | 支持代理设置；预置国产厂商（DeepSeek/智谱/Kimi/通义）默认直连可用；Ollama 本地方案兜底 |
| 用户误将 AI 输出当投资建议 | 每次回复附免责声明；文档与 UI 明示 |
| PyInstaller 被杀软误报 | 提供 onedir 模式备选与构建脚本，用户可自行重打包；README 说明加入白名单 |
| webhook 地址泄露风险 | 配置仅存本地；界面提示"机器人 webhook 等同密钥，请勿外传" |
| 策略过拟合 / 回测≠未来收益 | 回测输出样本内统计并明示局限；AI 解读时强制指出反向证据；信号附风险评分 |
