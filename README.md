## 这是什么

一个**开箱即用**的 A 股辅助决策工具（调研了 [go-stock](https://github.com/arvinlovegood/go-stock) 7.4k★、[TradingAgents](https://github.com/TauricResearch/TradingAgents) 102k★、[daily_stock_analysis](https://github.com/ZhuLinsen/daily_stock_analysis) 64k★、[akshare](https://github.com/akfamily/akshare) 22k★ 等开源项目后，按需求自研实现，数据接口与开源生态同源）：

| 功能 | 说明 |
|---|---|
| 🏠 首页工作台 | 打开即用：左「今日机会」自动扫描、中「我的自选」实时行情+7×24 快讯、右「AI 分析」面板——**所有分析就地展示，不跳页面** |
| 🔥 板块热力 | **49 个行业板块热度网格**（红涨绿跌热力色、成交额定字号、领涨股、点击进个股）+ **资金流向**：沪深两市主力净额双向条、板块成交额 TOP15 排行——**数字滚动/条形生长/热力渐入动画**，每分钟自动刷新重播 |
| 📈 行情看板 | 顶部四大指数常驻栏 + 自选**股票与 ETF**实时刷新（搜索联想支持代码/名称/ETF，腾讯主源，新浪备源） |
| 🕐 分时/五档 | 个股/**ETF**详情：分时图（**交易时段每15秒自动刷新**）、日/周/月 K 线（**副图 MACD/KDJ/RSI 可同时多选堆叠显示** + **压力/支撑位悬停显示** + **筹码分布图**）、五档盘口；右下角 **🤖 AI 悬浮助手**随时提问；**「AI 诊断」在详情窗内就地输出流式报告并可追问** |
| 🚀 涨停监控 | 涨停列表/封单金额/**强度分档**/连板高度/破50日新高/炸板标记 |
| 💾 本地K线缓存 | SQLite 存储，首次回填后扫描提速至秒级；**全市场快照并行拉取 + 主机熔断**（数据源限流时自动秒级降级不卡顿）；盘后 15:08 自动全策略扫描并推送「机会日报」到飞书/钉钉/企微 |

## 快速开始（普通用户）

1. 从 [Releases](../../releases) 下载最新便携版 zip（如 `StockPilot-v7.2.8-portable-win64.zip`），解压后双击 `StockPilot.exe`（无需安装 Python，无其他依赖）。
2. 行情页直接可用（内置免费数据源，无需注册/Token）。
3. AI 功能：到「设置」或「AI 分析」页选择厂商（如 DeepSeek），填入 API Key 与模型名，点「测试连接」→「保存配置」。
4. 通知（可选）：到「设置」页粘贴飞书/钉钉/企微机器人 webhook → 「发送测试消息」→ 勾选「启用推送」。
5. 监听（可选）：到「策略监听」页勾选「交易时段自动扫描全市场」（默认 5 分钟一轮），或点「立即扫描」。

> 首次启动若杀毒软件拦截，属 PyInstaller 打包常见误报，加入白名单或用源码自行打包（见下）。

## 快速开始（开发者）

```bash
pip install -r requirements.txt

python main.py            # 启动客户端
python main.py --smoke    # 自检（离线用例 + 真实接口连通性）
python -m pytest tests -q # 单元测试
scripts\build_exe.bat     # 一键打包 → dist\StockPilot.exe
```

要求：Windows 10/11 x64，Python 3.11+（开发环境 3.13 + PySide6 6.11 + PyInstaller 6.22）。

## 配置与数据

- 位置：exe 同目录 `data/config.json`（绿色便携）；不可写时回退 `%APPDATA%/StockPilot`。
- 内容：AI 多套配置、自选、自定义策略、监听信号记录、通知 webhook。
- 日志：`data/logs/app.log`（滚动 1MB×3）。

## 常见维护场景

| 场景 | 步骤 |
|---|---|
| 新增 AI 厂商 | `core/ai/vendors.py` 追加一个 `Vendor(...)` 即可（UI 自动出现） |
| 新增行情/资讯数据源 | 继承 `core/providers/base.py::Provider`，实现 `get_quotes/get_kline/get_news`，`@register_provider` 注册；在 `ui/context.py` 降级链中加入 |
| 行情接口字段变化 | 只改对应 provider 的解析函数（`parse_quote_text` / `parse_kline_json` 等），已有单测护航 |
| 新增策略指标 | `indicators.py` 加算法 → `analyze()` 输出到 ctx → 监听/回测/选股自动可用 |
| 新增内置策略 | `strategy.py::builtin_strategies()` 追加一条 |
| UI 视觉调整 | 所有设计令牌集中在 `ui/theme.py`（BG/PANEL/ACCENT/UP/DOWN 等），改一处全局生效 |
| 自定义策略 | 界面「策略监听 → 策略库 → 新建」即可；指标下拉为中文分组（72 项），规则形如"现价 高于 20日均线MA20"、"RSI6 介于 30~70"、"MACD金叉"；阈值也可填另一指标中文名做对比 |

## 已知限制与风险

- 腾讯/东财/新浪为**非官方公开接口**，可能限流或变更。程序内置三级降级（东财→腾讯→新浪），极端情况下部分功能不可用，重启或稍后再试。
- 新浪备用源无量比与周/月K线（量比自动用「日成交量/5日均量」等效兜底）。
- 钉钉机器人需在安全设置中配置关键词（消息自带「【股票机会】」前缀）或加签密钥。
- 指数代码（sh000001 等）与深市股票同数字时已按前缀区分；北交所代码（43/83/87/920 开头）已支持。
- **投资有风险**：本工具所有输出（行情、信号、回测、AI 建议）仅供学习研究，不构成任何投资建议。
